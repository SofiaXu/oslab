## 回归覆盖

参考验收相关的 Python 测试共 60 项：生产者消费者 11，四个算法实验 16，镜像/来宾 ABI/工作区/发布工具 18，进程统计 7，栈布局及反汇编 5，QEMU 失败清理 3。59 项通过，1 项明确跳过：原镜像没有超过 519 KiB 的普通文件，不能用它测试双重间接块；独立构造的双重间接块镜像用例已通过，不把跳过当作覆盖。

内核动态验收另外验证：

- 实验一：姓名往返、23/24 字节边界、空姓名、错误容量、NULL 与越段参数，以及失败不污染旧值。
- 实验三：三个实际子进程、五类内核事件、完整生命周期，15/5 两种基础时间片的日志导出和统计。
- 实验五：软件切换对象无 `ljmp/lcall/ltr`，默认及 12 轮加长负载通过，父子首次返回寄存器、x87 及舍入状态保持，退出和 wait 正常，shell 启动成功。
- 扩展：命名信号量参数及生命周期，阻塞/唤醒与过期句柄，文件缓冲的完整有序消费和资源回收。

这些检查不代替学生解释、AI 生成记录、手工栈图或未动态覆盖分支的单步调试。实验三使用有限队列和测量程序导出，**不是全启动至关机的内核直接磁盘日志**；具体边界见[指导书](lab03.md)。

## 复核位置

内核参考结果保留在本机 `build/lab01/reference/`、`build/lab03/reference/`、`build/lab05/reference/` 及 `build/lab02-kernel/reference/`：包含构建日志、实际来宾输出、VGA 文本画面、检查磁盘；实验三另有原始轨迹与统计 JSON。`build` 不纳入源码或学生包，重新执行对应 `make check-labN IMPL=reference` 即可生成本次机器自己的记录。

源码基线和根镜像分别通过 `vendor/linux-0.11.sha256` 与 `vendor/sources.json` 校验。学生发布包由 `make student-dist` 生成到 `dist/oslab-student.tar.gz`，排除参考源码、私有原材料、缓存、构建结果和上游差异补丁。
